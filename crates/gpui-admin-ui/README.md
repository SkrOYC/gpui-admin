# gpui-admin-ui

Shell, views, forms, and layout store for
[gpui-admin](https://github.com/SkrOYC/gpui-admin), built on `gpui-component`.

> **Status: in active development.** This crate is part of the pre-1.0
> gpui-admin project and is currently a documented placeholder; the public API
> is not yet available.

See the [repository](https://github.com/SkrOYC/gpui-admin) for details.
