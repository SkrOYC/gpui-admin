# gpui-admin

Native-UX-led desktop admin framework for Rust, built on GPUI. This is the
facade / prelude crate — what adopters `cargo add`.

> **Status: in active development.** This crate is part of the pre-1.0
> [gpui-admin](https://github.com/SkrOYC/gpui-admin) project and is currently a
> documented placeholder; the public API is not yet available.

See the [repository](https://github.com/SkrOYC/gpui-admin) and its
`.constitution/` for the full design.
