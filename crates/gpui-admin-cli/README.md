# gpui-admin-cli

The `gpui-admin` command-line tool for
[gpui-admin](https://github.com/SkrOYC/gpui-admin): schema introspection,
snapshotting, and scaffolding.

> **Status: in active development.** This crate is part of the pre-1.0
> gpui-admin project and is currently a documented placeholder; the command
> tree is not yet available.

See the [repository](https://github.com/SkrOYC/gpui-admin) for details.
