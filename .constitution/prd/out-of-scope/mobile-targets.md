# Out of Scope: Mobile Targets

**Status:** Rejected for the foreseeable product.
**Since:** v0.1.0.

## Context

Admin access from phones/tablets is occasionally requested of admin tooling.

## Decision

No mobile form factor is targeted.

## Reasoning

Every identity-defining capability — multi-panel docked Workspaces, dense data tables over millions of Records, keyboard-first operation — is a desktop workflow. A mobile admin is a different product with different Views, input models, and constraints; pretending otherwise would produce a bad phone app and a compromised desktop one.

## Reopening Conditions

None foreseen. A read-mostly companion surface would be a separate product definition, not an evolution of this one.
