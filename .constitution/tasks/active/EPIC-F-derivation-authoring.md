# EPIC F — Derivation & Authoring Surface

Closes the build-time spine (B3/B4 containers): the typed builder surface (ADR-002), derivation macros over committed Snapshots, drift-as-build-failure, the Scaffolder, and `check`. Exit criterion for Phase 1: the tracer bullet's hand-written code is deleted and regenerated by this pipeline with identical behavior.

#### GA-F001 Typed builder authoring surface

- **Type:** Feature
- **Effort:** 8
- **Dependencies:** GA-D003
- **Category:** Feature-Evolution
- **Scope (In-Scope Files):**
  - `crates/gpui-admin-core/src/resource/` (implements `tech-spec/contracts/resource_builder.rs`)
- **Scope (Out-of-Scope Files):**
  - `crates/gpui-admin-macros/` (GA-F002)
- **Verification Command:** `cargo test -p gpui-admin-core resource:: && cargo doc -p gpui-admin-core --no-deps`
- **Expected Success Output:** `exit 0`
- **STOP Conditions:**
  - "STOP if any builder method would accept a stringly field reference; typed field identity is the surface's reason to exist (ADR-002)."
- **Description:** Implement the normative builder API in full: `resource::<R>()`, Provider Binding key (default-binding fallback), `undo_window(Duration)` override, per-field config closures with the closed declarative `FieldRule` set plus closure escape hatch and `quick_edit()` restriction, relation declarations (`belongs_to`/`has_many` with typed targets; cross-binding accepted and marked UNVERIFIED; `many_to_many` over junction declarations), per-view projections with FormBuilder layout primitives (sections/columns), `build() → ResourceDecl`. Declarations are plain values: constructible in tests, iterable, registrable. The tracer resource's hand config is ported to it as the first consumer.
- **Acceptance Criteria (Gherkin):**
```gherkin
Given the tracer resource declared through the builder
When the declaration value is inspected in a unit test
Then field config, rules, layout sections, projections and relations match the hand-written original

Given a declaration whose relation targets another Provider's Resource
When registration runs
Then it is accepted, structurally verified only, and carries the UNVERIFIED marker

Given a declaration with a duplicate projection entry or a quick_edit on a rich widget
When registration runs
Then the startup assertion rejects it with a message naming the offense
```

- **Type:** Feature
- **Effort:** 8
- **Dependencies:** GA-E001, GA-F001
- **Category:** Feature-Evolution
- **Scope (In-Scope Files):**
  - `crates/gpui-admin-macros/src/`
- **Scope (Out-of-Scope Files):**
  - `crates/gpui-admin-cli/` (emission side is done; macros only consume)
- **Verification Command:** `cargo test -p gpui-admin-macros && cargo test -p gpui-admin-core derived::`
- **Expected Success Output:** `exit 0`
- **STOP Conditions:**
  - "STOP if derivation would read any file at expansion time; token-only operation is ADR-001's hermeticity guarantee."
  - "STOP if the derived tracer resource behaves differently from the hand-written one in any Epic C/D test; that divergence is the epic's failure signal."
- **Description:** The B4 engine: macros consuming committed Snapshot tokens to derive `Resource`/`FieldIdent` implementations, `FieldSet` widths, `CreatePayload` (server-owned exclusion), and registration glue — exactly the code Epic C wrote by hand. Format-marker check with the "re-run introspect" diagnostic. The tracer's hand-written derivation code is deleted and replaced; all Epic C/D suites must pass unchanged.
- **Acceptance Criteria (Gherkin):**
```gherkin
Given the tracer Snapshot module and its builder declaration
When the workspace builds with derivation replacing hand-written impls
Then every Epic C and Epic D test passes without modification

Given a Snapshot with an incompatible format marker
When the build runs
Then it fails with the re-run-introspect diagnostic naming both versions
```

#### GA-F003 Drift build-failure diagnostics

- **Type:** Feature
- **Effort:** 3
- **Dependencies:** GA-F002
- **Category:** Correctness
- **Scope (In-Scope Files):**
  - `crates/gpui-admin-macros/src/drift.rs`, `crates/gpui-admin-macros/tests/ui/` (compile-failure fixtures)
- **Scope (Out-of-Scope Files):**
  - `crates/gpui-admin-cli/src/cmd/check.rs` (GA-F005 reuses this logic)
- **Verification Command:** `cargo test -p gpui-admin-macros --test ui`
- **Expected Success Output:** `exit 0` (every fixture fails compilation with the expected pointed message)
- **STOP Conditions:**
  - "STOP if any drift case produces a generic mismatch error; NFC-12 requires the exact stale declaration and location."
- **Description:** The flow-drift-detection contract: each drift class (removed field referenced in config, nullability change contradicting `required`, relation target gone, projection over a vanished field) fails compilation with a span pointing at the stale declaration line. Compile-failure fixture tests lock the message quality.
- **Acceptance Criteria (Gherkin):**
```gherkin
Given a Snapshot regenerated with a field made nullable
When a stale required(true) declaration builds
Then compilation fails with a span on that exact builder call
And the message names the field and both truths
```
